# macOS 联调包

适用 macOS Apple 芯片（arm64）。同事无需安装 Python 或 uv，需先安装 Google Chrome。当前为内部联调包，使用临时签名，未做 Apple 公证；收到包后如被系统拦截，按 macOS“隐私与安全性”中的提示允许打开。

## 构建与启动

在 macOS arm64 开发环境执行：

```bash
uv sync --locked
uv run python deploy/build_macos.py
```

交付 `dist/shadow-agent-0.1.0-macos-arm64.zip`，解压后双击 `启动.command`，或在终端执行 `./shadow-agent`。关闭服务按 `Ctrl+C`。可执行 `./shadow-agent --check-runtime` 检查依赖，此命令不联网、不启动浏览器或操作桌面。

服务默认监听 `127.0.0.1:29321`，通过 `GET /version` 检查启动状态。桌面接管仍需用户确认，并按提示为实际运行程序或终端授予辅助功能、屏幕录制权限；开发机器的授权不会随包转移。

## 配置与运行数据

包内 `defaults/` 只有公开的 `.env` 和 `account_001` 浏览器配置，API Key 为空。首次启动复制到：

```text
~/Library/Application Support/Shadow/
├── .env
├── config/profiles/account_001/browser_profile.json
└── data/
    ├── agent_token.txt
    ├── agent.pid
    ├── logs/
    └── sessions/
```

Chrome 登录态位于账号配置指向的 `chrome_data/`。已有文件不会被默认模板覆盖；更换程序包保留用户目录即可。修改运行配置请编辑用户目录中的文件，再重启服务。发布包可在启动前设置 `SHADOW_HOME` 指向其他可写目录。

默认提供方、主模型和 Judge 为 `deepseek`、`deepseek-flash`、`deepseek-flash`。主模型和 Judge 共用同一 API Key。程序使用本机已安装的 Chrome；特殊安装位置可在账号配置中填写原生 `executable_path`，不会临时调用 uvx 下载浏览器。

## 宿主接入

宿主通过本地文件能力读取 `data/agent_token.txt`，后续请求均携带 `Authorization: Bearer <token>`。服务重启后重新读取 token。普通网页不能直接按路径读取该文件，需要宿主桥接；本轮未增加跨源访问配置。

前端先提交模型密钥：

```http
PUT /config/llm
Authorization: Bearer <token>
Content-Type: application/json

{"api_key":"由用户输入的模型密钥"}
```

- 200：`{"configured":true}`；只表示密钥已接收，不代表已向模型提供方验证可用性。
- 401：宿主 token 无效。
- 409：任务正在运行、等待人工处理或清理，结束后再修改。
- 422：请求格式错误；响应不回显提交值。
- 503：服务未就绪；任务提交时也用于提示尚未配置密钥。

密钥只保存在服务内存，不写入 `.env`、日志或响应；重启后由前端重新提交。宿主也应避免记录请求体或将密钥放到 URL。

随后调用 `POST /task`，示例：

```json
{ "account_id": "account_001", "params": { "task": "访问 https://example.com 并读取页面标题" } }
```

状态查询、恢复和取消接口见项目 README；接口字段也可查服务的 `/docs`。

## 交付边界

构建只收集程序依赖、公开配置模板及本说明；不复制开发机 `.env`、账号目录、登录态、token、审计、存档或本地调试页。压缩包可直接交给同事，首次启动生成独立的本地数据。

当前只构建 macOS arm64；Windows、Intel Mac 和其他 macOS 版本需对应环境另行验证。PyInstaller 的平台和运行路径说明见[官方文档](https://pyinstaller.org/en/stable/runtime-information.html)，Apple 签名与公证说明见[官方文档](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution)。
