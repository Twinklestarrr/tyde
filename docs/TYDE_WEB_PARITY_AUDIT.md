## 页面回归中发现并纠正的行为

- 转项待办已明确进入 `ENTRANCE_EXAM` 时，按该来源进入目标项目考试；项目初始笔试开关不再覆盖服务端已经下发的考试分支。取消成功后回项目卡片；回读失败时说明考试已取消，只重读待办，不重发取消。
- 非主策略官能读取实际人工阅卷轮次时，配置候选接口的 403 或 503 不阻断阅卷回读。提交成功、读取到完成成绩后结束等待提示；其他角色不能借原角色的草稿提交。
- 从人员管理的生产情况保存质量记录，只刷新生产列表和质量历史；两者成功后关闭明细，仍停留在生产情况。回读失败保留明细和已保存事实，可只重读；不刷新未打开的花名册，也不因工作台待办接续切走。入项仍读原花名册核实。

- 富文本内核无法解析历史正文时，保留原始内容并改用可编辑文本框；编辑实际同步到表单，仍执行完整请求 16 KiB 上限，不运行正文中的 HTML 或脚本。正常 Markdown 沿用旧版编辑和预览。
