## 交卷与取消

```json
{
  "projectId": 1,
  "attemptId": 1,
  "integritySigned": true,
  "answers": [
    { "questionId": 1, "answerContent": "先核验数据，再记录质检结果。", "answerFiles": [] }
  ]
}
```

须提供本人已入场且属于本项目的attemptId，integritySigned必须true。整卷请求体最多2MiB（UTF-8字节），超过返回413。最多500项；题目必须属于绑定试卷且不得重复。每题文字最多100000字符，去除首尾空白；必答题文字或附件至少有一项，选答题可省略，服务端仍保存空答案。因此answerCount为全卷题数。

每题answerFiles省略/null/空数组为无附件，最多10个；附件项沿用考试文件字段，必须提供本人新上传的ENTRANCE_EXAM_ATTACHMENT的objectKey和uploadToken，uploadedFileId须省略或null，其他回显元数据忽略。禁止同卷重复文件、跨用户凭证、复用已认领附件或参考答案文件；台账认领、答案保存和阅卷创建在同一事务。

答案提供实际paperId与questionId；每轮逐题项绑定同一attemptId/questionId/answerId。轮次使用入场绑定版本，首轮PENDING、后续WAITING；MANUAL首轮同步待办/快照和PENDING outbox，AUTO首轮只持久化provider=mock、executionStatus=NOT_EXECUTED的派发请求，不访问真实Agent、不启动后台定时器。按[自动阅卷说明](ENTRANCE_EXAM_MANAGEMENT.md)显式mock领取、成功/失败回调、重试及补偿；上一轮完成才激活下一轮。

交卷与取消按用户→组织→关系→项目→应试锁串行化，一方成功后另一方拒绝。交卷同时记录诚信签署时间、完成本人考试轮次并撤卡；取消仅记录cancelledAt、取消事件及撤销考试轮次，不保存答案/阅卷/入项。超时可取消，取消后不可再次进入，任务列表不再显示考试按钮。两者均不推进项目主线或版本。最终判卷通过沿现有05逻辑生成PENDING_CONFIRM、joinedAt=null，实际入项确认归10；取消不伪造最终阅卷结果。
