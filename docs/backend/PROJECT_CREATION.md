## 认证与范围

两个入口只要求有效登录及本人范围，不额外要求NAVIGATOR。统一账号自带三角色，分类查询/需求方回填等NAVIGATOR入口校验服务端当前会话角色；项目归属仍另行检查，详见[管理角色说明](UNIFIED_ACCOUNTS.md)。

Web使用HttpOnly Cookie，写请求遵循可信Origin校验；普通API/桌面使用Bearer，禁止凭据混用。草稿查询只按认证UID定位本人唯一未删除草稿，不接受目标用户ID。创建时可省略requesterType/requesterId，由服务端取当前用户；传入时类型必须匹配、ID必须为本人，否则400/403。当前创建入口只接受本人INDIVIDUAL需求方，ORGANIZATION返回400；组织成员关系不会自动改变需求方身份，不接受客户端组织ID或需求方名称。

## 保存与发布规则

请求是完整快照。省略/null会清空旧字段，文本trim后空白转null；educationRequirement省略/null统一回落BACHELOR，包括更新已有草稿。附件是例外：省略/null保留原附件，空数组移除全部，其余数组表示完整保留集合和新认领文件。仅operation必填；旧字段名、枚举、字段级规则及完整请求/响应示例见Swagger。

每个创建人最多一份未删除DRAFT。首次保存版本为0，已有草稿必须传versionNo：缺失400、过期409，成功更新递增1。保存先锁用户行，再检查本人需求方、草稿、分类及附件；项目写入、分类名称快照完整替换、附件认领和移除均在同一数据库事务中。数据库另有未删除草稿和已发布同名项目的部分唯一索引（Prisma模型无法表达，维护于迁移SQL）。事务失败不会消耗上传凭证、改变版本或部分删除附件。

已填数量、人数必须大于0；人数为32位整数。projectQuantity存DECIMAL(20,4)，超过4位小数按数据库规则舍入，API继续返回JSON数值。deadline接收/返回上海本地`yyyy-MM-dd HH:mm:ss`，拒绝不存在的日历时间和ISO后缀；须晚于草稿创建时间，首次保存以当前时间为基准，不擅自改为“每次都必须晚于当前时间”。数据库保存带时区时间，接口明确转换，不依赖部署进程时区。

发布要求：项目名称、一级分类、二级分类、至少一个三级分类、难度、量级、单位、截止时间、需求人数、用工类型、标准正文和必备要求。学历按默认值补全。此处以旧Service实际规则为准：旧字段文案称描述/工作简介必填，但代码不强制；标准链接也不能代替标准正文。未获产品变更决定前不修正这些业务差异，Swagger已如实说明。

三个分类级别独立。选择时必须存在、ENABLED且级别匹配，三级最多20个、不重复、按请求顺序保存；草稿查询显示关联中的名称快照，不随字典改名改变。查询个人需求方名称按当前昵称(姓名)回填，组织使用保存时快照。creatorName沿用旧创建服务未填充行为返回null，不用于授权；草稿不返回productionRequirements。

发布检查同需求方账号下未删除PUBLISHED项目同名冲突；同名返回409。按旧SQL实际以requesterType+requesterId（用户ID）为范围，不擅自改为同orgId全组织共享去重。发布后项目进入RECRUIT_PROJECT_MANAGER，草稿查询不再返回该项目，后续保存可以创建新草稿。项目编号首次生成后不变；发布不创建策略官任职、成员、生产计划或考试，不伪造后续能力。

本接口没有发布幂等键。并发首次草稿创建一个成功、其余因缺版本失败；同版本并发更新一个成功、其余409；同需求方同名并发发布只允许一个成功。发布成功后重复不同内容请求有可能创建另一项目，调用方不得将其当作带幂等键的提交接口。

## 附件事务与读取

新附件先登录调用文件上传，bizType=PROJECT_ATTACHMENT，再提交attachmentType、objectKey、uploadToken。用途为STANDARD_REFERENCE/CASE/OTHER；只信任上传台账中的名称、大小、哈希等元数据，不接受附件旧元数据字段。一次性凭证、用户上传归属、业务类型、未认领/未过期和实际对象大小均须校验，成功认领到该项目，凭证不返回草稿响应。

保留已有ACTIVE附件可只传附件id或objectKey，不重复认领；此时不修改用途，指定sortNo可更新排序，未传保持旧值。新增sortNo默认0。重复ID/Key、其他项目附件和已删除附件拒绝。未列出的旧附件变DELETED、台账变RELEASED并设置延迟回收时间，不在事务中物理删除对象。

API-011项目附件读取要求上传台账CLAIMED、绑定项目ID、附件ACTIVE且项目未删除。当前NAVIGATOR会话须为项目创建人；当前PM会话须为ASSIGNED主策略官或招募协作负责人，任职失效后下一请求拒绝。当前EXPERT会话通过接单、组织职责及准入等真实业务来源校验；上传者或ACTIVE项目成员身份本身不构成下载权限。考试附件按绑定试卷、本人答案或实际阅卷/组织职责范围单独校验。
