# 工作台非空项目真实联调

2026-10-27：Web 与实际 Electron 分批完成三角色非空项目联调。页面直连本机真实业务服务及专用 `_test` PostgreSQL，不拦截业务响应；成功样本每端使用独立的四个账号、三个项目及一个组织。

| 角色     | 本轮实际操作                                                                                                             | Web  | Electron |
| -------- | ------------------------------------------------------------------------------------------------------------------------ | ---- | -------- |
| 领航员   | 非空列表筛选/刷新、创建入口、详情刷新与资料弹窗、候选查询/重置、指定与替换策略官（均先取消确认再真实提交）、当前任职回读 | 通过 | 通过     |
| 策略官   | 非空列表与详情、人群和阶段增删、确认弹窗继续填写及最终确认、只读回读、刷新恢复和模块切换                                 | 通过 | 通过     |
| 执行专家 | 非空列表搜索/刷新、真实分配详情、个人接单与拒绝、组织主管查询并选择真实负责人接单、普通成员接单与本人项目回读            | 通过 | 通过     |

每端记录 76 条页面业务 HTTP 响应，全部为 200，页面异常为零；其中七次业务写入分别是指定/替换策略官、确认生产计划和四次接拒单。两端合计 152 条响应、14 次业务写入。指定后主线进入生产计划，计划确认后进入标准培训；接拒单后的待办增减、招募统计及本人参与项目均回读核对。

联调修复了项目共享路由遗漏 `desktopOrigins` 导致 Electron 写请求 403 的问题，仍严格拒绝未知来源。专家新增已有接拒单和负责人候选接口的客户端适配与操作弹窗；未知写结果先读取当前任务，关闭弹窗不能绕过核实，已成功写入后即使回读失败也不恢复旧提交按钮。

验证还包括 186 项 core、43 项后端定向及 20 项页面回归；最后一组覆盖新增失败恢复与三角色切换。共享包、平台、Web、服务端类型检查，Web/服务端/Electron 构建及变更 ESLint/Prettier 通过。

项目发布、任职、计划、标准推进和招募均经真实 HTTP 产生；数据库仅准备本批分类和组织成员关系及清理本批测试会话，没有人工跳过等待节点。失败重试夹具保留在专用库；本轮 20 个独立测试账号的剩余有效会话已全部撤销。自启测试服务和桌面进程已清理。未新增迁移，未操作开发/部署库或发布。

本批项目没有附件，附件下载不计本批验收。考试、培训、招募管理、人员管理与生产等标为“入口暂未开放”的页面只验证可切换及文案，未将其计为业务写流程已联调；入项等待及后续业务仍按原任务推进。
